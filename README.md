# 🔐 Tela de Login Customizada e Interativa

![HTML5](https://img.shields.io/badge/HTML5-E34F26?style=flat&logo=html5&logoColor=white)
![CSS3](https://img.shields.io/badge/CSS3-1572B6?style=flat&logo=css3&logoColor=white)
![JavaScript](https://img.shields.io/badge/JavaScript-F7DF1E?style=flat&logo=javascript&logoColor=black)

Interface de **login e cadastro** moderna, colorida e totalmente interativa, feita com HTML, CSS e JavaScript puro. Um projeto focado em design de interface e experiência do usuário.

---

## ✨ Funcionalidades

- 🔐 **Telas de login e cadastro** em uma mesma interface
- 🔄 **Alternância interativa** entre entrar e criar conta
- 🎨 **Visual colorido e moderno**, com atenção aos detalhes
- ✨ **Interações e animações** que deixam a navegação fluida
- 📱 Interface pensada para uma boa experiência de uso

---

## 🛠️ Tecnologias

- **HTML5** — estrutura
- **CSS3** — estilo, cores e animações
- **JavaScript** — interações e alternância de telas

> Feito com tecnologias puras, sem frameworks.

---

## 🚀 Como visualizar

**Opção 1 — abrir localmente:**

git clone https://github.com/JoaoVitorArantesGomes/Tela_de_login_customizada_interativa.git

Depois é só abrir o arquivo `index.html` no navegador.

**Opção 2 — hospedar no GitHub Pages** para gerar um link de demonstração online (recomendado para o portfólio).
